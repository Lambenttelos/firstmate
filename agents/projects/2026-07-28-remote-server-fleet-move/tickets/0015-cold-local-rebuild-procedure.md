# Write the cold local rebuild procedure

Type: `wayfinder:task`. Status: open. Blocked by: Cut over the remaining clones, records, and scheduled work.

## Question

If the server dies as hardware, what precisely does the captain do to get a working local home back?

## Why this matters

The single-home decision is only defensible if the recovery path is written down before it is needed.
Working it out during an outage is how a deliberate trade turns into an incident.

The procedure also has to be honest about what is lost, which is any fleet state not covered by the backup decision.

## Resolved when

The procedure exists, names its inputs, and has been walked through at least on paper against the backup that actually exists.
