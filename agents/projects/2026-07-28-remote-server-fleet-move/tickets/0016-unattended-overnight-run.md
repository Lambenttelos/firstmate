# Prove one unattended overnight run on the server

Type: `wayfinder:task`. Status: open. Blocked by: Cut over the remaining clones, records, and scheduled work.

## Question

Does an away-mode session run overnight on the server without the captain present, and hold together until morning?

## Why this shape

This is the stage three gate and the destination condition for this map.
Away mode is the hardest thing the fleet does, because it exercises supervision, escalation, the scheduled wakes, and the delivery paths with nobody watching.

## Resolved when

One overnight session runs, escalations reach the captain the way they are supposed to, and the morning state is coherent rather than needing repair.
